# 🚀 Nexus ERP System

A full-featured **Enterprise Resource Planning (ERP)** system built using **Flask, MySQL, HTML, CSS, JavaScript, and Bootstrap**.

---

## 📌 Features

### 👥 Human Resource (HR)

* Employee Management
* Attendance Tracking
* Leave Management
* Payroll System

### 📊 Dashboard

* Real-time analytics
* Charts & reports

### 💰 Finance

* Expense tracking
* Financial overview

### 📦 Inventory

* Product & stock management

### 🛒 Sales

* Sales tracking
* Customer management

### 📁 Projects

* Task & project management (Kanban board)

### 📧 Messaging System

* Internal mail system

### 🔔 Notifications

* Real-time alerts

### 🤖 AI Integration

* Smart AI assistant (Gemini/OpenAI based)

---

## 🛠️ Tech Stack

* **Backend:** Flask (Python)
* **Database:** MySQL
* **Frontend:** HTML, CSS, JavaScript, Bootstrap
* **Charts:** Chart.js
* **Icons:** Bootstrap Icons

---

## ⚙️ Installation (Local Setup)

```bash
git clone https://github.com/ATIKSAIYAD27/erpsystem.git
cd erpsystem
pip install -r requirements.txt
python app.py
```

---

## 🔐 Environment Variables

Create a `.env` file:

```env
DB_HOST=localhost
DB_PORT=3307
DB_USER=root
DB_PASSWORD=
DB_NAME=erpsystem
```
